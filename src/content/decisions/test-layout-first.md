## Context

The end goal is a larger **full-room layout**. Getting there means building a control system from scratch (a
command station, sensor nodes, an orchestrator and a throttle) and a lot of hands-on work: baseboards, track,
wiring and scenery.

## Decision

Build **Westgate Hollow Yard** first: a small OO gauge test goods yard, used to

- **verify the control systems** on real track with real locos and sensors,
- **try out scenic techniques**, and
- **practise generally** before the full-room layout.

## Consequences

- The control system gets proven on real track before it has to run anything bigger.
- Scenic techniques get tried out on the test layout first.
- Westgate Hollow is a stepping stone, not the final layout.
